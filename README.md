# 🧠 PocketBrain — Your AI-Powered Second Brain

> A personal knowledge system that remembers, understands, and connects what matters to you.

PocketBrain is a context-aware personal knowledge system designed to help people
capture information with minimal effort, understand the relationships between
the things they save, and rediscover useful information when it becomes relevant.

Instead of becoming another place where information is stored and forgotten,
PocketBrain aims to become a personal memory layer that grows with the user.

---

## 🌱 The Idea

We save things every day.

A reel we want to watch later.
A useful YouTube video.
A PDF.
A screenshot.
A random thought.
A piece of text copied from somewhere.
A conversation.
A sketch.
A link.
An unfinished idea.

The problem isn't always **saving** information.

The problem is finding it again when we actually need it.

PocketBrain is built around a simple idea:

### Capture → Understand → Rediscover

Capture information without unnecessary organization.

Let PocketBrain understand the context and relationships between it.

Rediscover it when it becomes useful again.
